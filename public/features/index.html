Function Overview

功能介紹

放射師國考刷題庫以醫事放射師國考準備為核心，提供歷屆試題練習、錯題整理、收藏題與個人成長追蹤功能。

開始刷題 查看題庫功能

歷屆試題練習

依考科與年份範圍載入歷屆試題，並以單科限時測驗方式安排日常刷題。

  • 歷屆試題刷題
  • 科目分類練習
  • 作答結果檢視

個人複習工具

作答後可把高風險題目集中管理，協助考前快速回顧與補強弱點。

  • 錯題本
  • 收藏題
  • 最近作答紀錄

模擬考

以單科限時測驗模式模擬正式考試情境，協助掌握當次表現與考前狀態。

  • 單科限時測驗
  • 測驗結果檢視
  • 答對答錯整理

我的成長

透過最近 7 天作答概況、科目戰力與錯題清除進度，查看自己的學習節奏與弱科分析。

  • 個人成長追蹤
  • 弱科分析
  • 錯題清除進度
